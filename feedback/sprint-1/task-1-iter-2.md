### РЕКОМЕНДАЦИИ 💡

- Можно применить семантичный тег search, обернув в него form
- У input есть type=search
- .weather__state-icon создали пустой div для иконки, можно было его убрать, а иконку сделать псевдоэлементом span'а
- Про label к input уже писали
- Border-radius можно вынести в переменную, он везде по 8px
- В CSS есть вложенность нативная (nesting), можно писать так .search {&:hover: background: var(--search-hover)}
- Вы прописали font-family: var(--main-font); для всего *, и применяете font-family: Raleway; для .search__input. Он без явного указания возьмет шрифт из *. В консоли в стилях хорошо видно. Вы один и тот же шрифт перезаписываете
- В проекте есть только blur(25px), у вас есть плюсом переменные blur 10px и blur 50px, которые не применяются. В макете blur 50px, но из за особенностей фигмы, это значение нужно поделить на 2, чтобы совпало, поэтому применяем 25px.
- 4 раза применяете одни и те же стили для текста в weather.css, можно повесить один раз на родителя, вам об этом писали
- currenQuerry опечатались в названии в JS
- Вы применяете h1, h2 и потом сразу h6, так нельзя делать, они должны идти по порядку, если у секции главный заголовок h2, то внутри пойдет h3, потом h4, пропускать нельзя. Рекомендую проверять валидатором разметку [https://validator.w3.org/](https://validator.w3.org/) , сейчас он пишет 2 error'а как раз из за заголовков.
