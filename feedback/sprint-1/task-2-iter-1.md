## Infinity (Maria) – ⭐ 5

### ПЛЮСЫ 👍

Хорошая работа , легко читаемый код , макет полностью соответствует.

### БАГИ 🐞

- В ТЗ сказано: *«в рамках этого задания выполняется только верстка блока карточек с заполнением данных... функционал получения актуальных данных не требуется»*. Однако ты заложил структуру, которая **не сможет** работать с динамическими данными в будущем. Ты вставил шкалы прогресса готовыми статичными картинками под конкретные цифры (75%, 761мм).
**Как исправить:** Шкала должна быть свёрстана с помощью CSS (например, через ``<progress>``, `linear-gradient` или кастомное свойство `style="--progress: 75%"`), а в данных должно храниться чистое число, а не путь к картинке.

### РЕКОМЕНДАЦИИ 💡

1. `index.html` и `main.js`
Общий заголовок секции карточек имеет тег ``<h3>`` (`.cards__title`), а заголовки внутри самих карточек рендерятся как ``<h2>`` (`.cards__item-title`). По правилам семантики подзаголовки элементов не могут быть старше заголовка всей секции.

2. Массив `weatherData` объявлен в обычном скрипте без модульной системы, из-за чего он автоматически попадает в глобальный объект `window`. Стоит переписать файлы на ES6-модули (`export / import`), добавив тегам скриптов атрибут `type="module"`.

3. **Нарушение валидности HTML5:** В index.html внутри тега списка `<ul>` подключены скрипты:

`<ul id="weatherCards" class="cards__list">`

`<script src="./data.js">``</script>`

`<script src="./main.js">``</script>`

`</ul>`

По стандартам HTML, дочерними элементами `<ul>` могут быть **только** теги `<li>`.

4. В HTML - `<div class="weather__state-icon">``</div>`
Картинка с пустым тегом в `<div>` с фоном через background-image, скринридеры (программы для незрячих людей) её просто «не видят» и пропускают. Для них этот блок остаётся невидимым и нечитаемым.

- **Как исправить:** Заменить `<div>` на семантичный тег `<img>` с обязательным атрибутом alt (описание картинки для доступности) или использовать встроенный `<svg>` с тегом `<title>` внутри:

HTML

`<img class="weather__state-icon" src="./images/cloudy.svg" alt="Облачно">`
